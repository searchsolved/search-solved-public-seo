# Keyword Gap Analyzer

## Features

Compare your keyword list against competitors to find gap opportunities. Uses TF-IDF vectorization for intelligent similarity matching.

- Streamlit web interface
- Upload multiple keyword lists for comparison
- TF-IDF similarity analysis
- Identify missing keyword opportunities
- Export results to CSV
