# SERP Crossover Analyzer

## Features

Analyze SERP results across multiple keywords to identify URL crossover patterns. Great for finding keyword cannibalization and topic overlap opportunities.

- Streamlit web interface + CLI version
- Fetches SERP results for multiple keywords
- Identifies URLs ranking for multiple queries
- Detects keyword cannibalization patterns
- Export analysis to CSV
