# Category Title Suggester

## Features

Analyze category page titles against GSC performance data to suggest high-performing keywords that could improve your titles.

- Streamlit web interface + CLI version
- Upload GSC data and page titles
- Identifies keywords driving traffic not in titles
- AI-powered title suggestions
- Export recommendations to CSV
