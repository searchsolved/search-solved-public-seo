# Content Duplication Finder

## Features

Find duplicate content clusters in your Screaming Frog crawls using PolyFuzz fuzzy matching with configurable similarity thresholds.

- Streamlit web interface
- Upload Screaming Frog crawl exports
- PolyFuzz TF-IDF similarity matching
- Configurable similarity thresholds
- Cluster duplicate pages for consolidation
- Export results to CSV
