# Content Extractor

## Features

Extract main text content and H1 headings from URLs using multi-threaded requests. Useful for content audits and analysis.

- Streamlit web interface + CLI version
- Multi-threaded URL fetching
- BeautifulSoup content extraction
- Extracts H1 headings and main content
- Export to CSV for analysis
