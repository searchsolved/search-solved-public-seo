# Content Repurposer

## Features

Transform blog posts into multiple content formats using AI. Generate social posts, email content, and video scripts from existing articles.

- Streamlit web interface
- Claude and GPT API support
- Generate social media posts
- Create email newsletter content
- Video script generation
- Multiple output formats
