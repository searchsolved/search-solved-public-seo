# Content Reviewer (LLM)

## Features

Review and annotate web content using AI to provide quality improvement suggestions. Supports OpenAI and Anthropic APIs.

- Streamlit web interface
- OpenAI and Anthropic API support
- Content quality analysis
- Improvement recommendations
- SEO-focused suggestions
- Export annotated reviews
