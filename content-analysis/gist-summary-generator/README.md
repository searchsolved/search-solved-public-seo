# Gist Summary Generator

## Features

Create "At a glance" bullet point summaries from articles and content using Claude or GPT AI models.

- Streamlit web interface
- Claude and GPT API support
- Generate concise bullet summaries
- Perfect for featured snippets
- Batch processing support
- Export summaries to CSV
