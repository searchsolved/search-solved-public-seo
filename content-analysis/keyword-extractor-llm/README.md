# Keyword Extractor (LLM)

## Features

Extract and categorize keywords from content using OpenAI or Anthropic APIs. Useful for internal linking and identifying new page opportunities.

- Streamlit web interface
- OpenAI and Anthropic API support
- Categorized keyword extraction
- Internal linking suggestions
- New page opportunity identification
- Export keywords to CSV
