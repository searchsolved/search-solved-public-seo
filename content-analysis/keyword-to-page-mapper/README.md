# Keyword to Page Mapper

## Features

Semantically match competitor keywords to your existing pages using Sentence Transformers and PolyFuzz.

- Streamlit web interface + CLI version
- Sentence Transformer embeddings
- PolyFuzz semantic matching
- Match competitor keywords to your H1s/titles
- Identify content gaps
- Export mappings to CSV
