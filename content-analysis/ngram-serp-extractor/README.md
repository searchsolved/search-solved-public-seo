# N-gram SERP Extractor

## Features

Extract page titles and content n-grams from SERP results using ValueSERP API for title optimization analysis.

- Streamlit web interface
- ValueSERP API integration
- Extract n-grams from SERP titles
- Identify common phrase patterns
- Title optimization insights
- Export analysis to CSV
