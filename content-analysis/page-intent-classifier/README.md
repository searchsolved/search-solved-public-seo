# Page Intent Classifier

## Features

Analyze web pages and classify their intent using GPT. Identifies primary purpose and expected user actions.

- Streamlit web interface + CLI version
- GPT-powered analysis
- Intent classification (informational, transactional, navigational)
- User action prediction
- Batch processing support
- Export classifications to CSV
