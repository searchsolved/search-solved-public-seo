# Review Sentiment Extractor

## Features

Analyze product reviews using OpenAI GPT to extract positive/negative sentiments, pain points, and praise themes.

- Streamlit web interface + CLI version
- OpenAI GPT integration
- Sentiment classification
- Pain point extraction
- Praise theme identification
- Batch review processing
- Export analysis to CSV
