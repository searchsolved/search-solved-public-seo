# Breadcrumb Relevancy Checker

## Features

Check if products are assigned to relevant categories by comparing product titles vs breadcrumb paths using PolyFuzz TF-IDF matching.

- Streamlit web interface + CLI version
- PolyFuzz TF-IDF similarity matching
- Product title vs breadcrumb analysis
- Identify miscategorized products
- Relevancy scoring
- Export results to CSV
