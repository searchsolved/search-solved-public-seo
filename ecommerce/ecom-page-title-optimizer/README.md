# E-commerce Page Title Optimizer

## Features

Analyze page titles against GSC keyword data to identify keywords ranking that aren't in titles and suggest optimization improvements.

- Streamlit web interface + CLI version
- GSC data integration
- Keyword gap analysis
- Title optimization suggestions
- Identify high-impact opportunities
- Export recommendations to CSV
