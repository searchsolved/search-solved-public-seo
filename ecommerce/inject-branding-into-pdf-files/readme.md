# Inject Branding into PDF Files

## Features

Automatically inject custom branding (text, logos, colors) into PDF files. Perfect for adding consistent branding to supplier PDFs, product sheets, or documentation.

- Add custom text overlays with configurable fonts and colors
- Process multiple PDFs in batch
- Configurable positioning and styling
