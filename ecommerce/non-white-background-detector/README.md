# Non-White Background Detector

## Features

Analyze product images to detect non-white backgrounds for e-commerce quality assurance using PIL image analysis.

- Streamlit web interface + CLI version
- PIL image analysis
- Background color detection
- Batch image processing
- QA for product photography
- Export flagged images to CSV
