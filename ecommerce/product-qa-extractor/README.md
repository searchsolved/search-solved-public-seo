# Product Q&A Extractor

## Features

Extract product reviews, ratings, and Q&A content from e-commerce pages with configurable CSS selectors.

- Streamlit web interface + CLI version
- Configurable CSS selectors
- Extract reviews and ratings
- Q&A content extraction
- Multi-threaded scraping
- Export to CSV
