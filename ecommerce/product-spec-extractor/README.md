# Product Spec Extractor

## Features

Scrape product specifications from e-commerce pages with configurable CSS selectors and rate limiting.

- Streamlit web interface + CLI version
- Configurable CSS selectors
- Rate limiting for polite scraping
- Specification table extraction
- Multi-threaded requests
- Export specs to CSV
