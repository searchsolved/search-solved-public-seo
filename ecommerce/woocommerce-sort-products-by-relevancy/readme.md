# WooCommerce Sort Products by Relevancy

## Features

Automatically sort WooCommerce products by relevancy within their categories using fuzzy matching. Ensures products appear in the most logical order based on category names.

- Connects to WooCommerce API
- Uses fuzzy matching to calculate product-category relevancy scores
- Automatically reorders products within categories
- Handles pagination for large catalogs
