# Semantic Clustering - Python Script Version

## Features

Standalone Python script version of the semantic keyword clustering tool. Run locally without Streamlit or Google Colab.

- Command-line interface
- Process large keyword lists locally
- Groups keywords into topical clusters using sentence embeddings
