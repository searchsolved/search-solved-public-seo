# Category Keyword Finder

## Features

Extract n-gram keyword opportunities from product titles grouped by category to identify common phrases and new category page opportunities.

- Streamlit web interface + CLI version
- Product title analysis
- N-gram extraction by category
- Identify common phrases
- New category page opportunities
- Export keywords to CSV
