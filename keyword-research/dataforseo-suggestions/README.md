# DataForSEO Suggestions

## Features

Get keyword suggestions with search volumes from the DataForSEO API for keyword research and expansion.

- Streamlit web interface + CLI version
- DataForSEO API integration
- Search volume data
- Related keyword suggestions
- Bulk keyword processing
- Export results to CSV
