# Keyword Deduplication Tool

## Features

Find and remove close variations of keywords from keyword lists using RapidFuzz fuzzy matching.

- Streamlit web interface
- RapidFuzz similarity matching
- Configurable similarity threshold
- Remove near-duplicate keywords
- Preserve unique variations
- Export deduplicated list to CSV
