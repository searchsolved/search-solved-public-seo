# Keyword Trends Analyzer

## Features

Analyze Google Trends data for keywords, calculate year-over-year trend slopes to identify growing or declining opportunities.

- Streamlit web interface + CLI version
- Google Trends integration
- YoY trend slope calculation
- Identify rising keywords
- Seasonal pattern detection
- Export analysis to CSV
