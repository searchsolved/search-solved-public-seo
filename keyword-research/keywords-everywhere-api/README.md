# Keywords Everywhere API

## Features

Keyword research tool using Keywords Everywhere API for search volume data and keyword suggestions.

- Streamlit web interface + CLI version
- Keywords Everywhere API integration
- Search volume data
- CPC and competition metrics
- Keyword suggestions
- Export results to CSV
