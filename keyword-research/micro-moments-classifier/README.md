# Micro-Moments Classifier

## Features

Classify keywords into Google's 4 micro-moments (I-want-to-BUY, KNOW, DO, GO) using OpenAI API.

- Streamlit web interface + CLI version
- OpenAI API integration
- Google micro-moments framework
- Intent classification
- Batch keyword processing
- Export classifications to CSV
