# Related Searches Tree

## Features

Build hierarchical trees of related searches from Google using ValueSERP API with configurable depth and visualization.

- Streamlit web interface + CLI version
- ValueSERP API integration
- Configurable search depth
- Tree visualization
- Related search mapping
- Export trees to CSV
