# Link Building Tools

Tools for analyzing backlink profiles and identifying link building opportunities. These tools help assess link quality and find common backlink sources across competitors.

## Tools Overview

### 🔗 **Backlink Intersector**
Find domains that link to multiple competitors but not to you.
- **Use Case**: Competitor backlink analysis, link prospecting
- **Input**: Backlink exports from Ahrefs, Semrush, or Moz
- **Output**: Domains linking to X competitors, sorted by opportunity
- **Features**: Multi-competitor analysis, filtering options, export to CSV

### 📊 **Link Quality Analyzer**
Assess the quality of backlinks using multiple metrics and signals.
- **Use Case**: Link audits, prospect qualification
- **Input**: List of referring domains or backlink data
- **Output**: Quality scores with contributing factors
- **Features**: Multiple quality signals, batch processing, scoring breakdown

## Use Cases

### 🎯 **Link Prospecting**
- Find sites that link to competitors but not you
- Identify patterns in competitor link profiles
- Prioritize outreach targets by potential value

### 🔍 **Link Audits**
- Assess overall backlink profile quality
- Identify potentially harmful links
- Benchmark against competitors

### 📈 **Competitive Analysis**
- Understand competitor link strategies
- Find common link sources in your niche
- Identify gaps in your link profile

## Quick Start

### Backlink Intersector
```bash
cd backlink-intersector
pip install -r requirements.txt
streamlit run backlink_intersector.py
```

### Link Quality Analyzer
```bash
cd link-quality-analyzer
pip install -r requirements.txt
streamlit run link_quality_analyzer.py
```

## Input Requirements

### **Backlink Intersector**
- Backlink exports from SEO tools (Ahrefs, Semrush, Moz)
- At least 2 competitor backlink files
- Your own backlink file (for gap analysis)

### **Link Quality Analyzer**
- CSV with referring domains
- Optional: Additional metrics (DA, DR, traffic)

## Output Formats

- **CSV files** with prospect lists
- **Quality scores** with breakdowns
- **Intersection analysis** showing shared links

## Best Practices

### 🔗 **Link Prospecting**
1. Focus on relevance over quantity
2. Prioritize domains linking to multiple competitors
3. Check link context before outreach
4. Track outreach success rates

### 📊 **Link Analysis**
1. Regular audits of your backlink profile
2. Monitor competitor link acquisition
3. Disavow clearly harmful links
4. Document link building wins
