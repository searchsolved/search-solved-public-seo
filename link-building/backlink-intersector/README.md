# Backlink Intersector

## Features

Find link building opportunities by intersecting competitor backlink profiles to identify pages linking to competitors but not to you.

- Streamlit web interface + CLI version
- Multiple competitor comparison
- Identify link gaps
- Domain intersection analysis
- Prioritize outreach targets
- Export opportunities to CSV
