# Link Quality Analyzer

## Features

Extract internal links from pages, check HTTP status codes, and calculate reading metrics to find broken links and spammy patterns.

- Streamlit web interface + CLI version
- Internal link extraction
- HTTP status checking
- Reading metric calculation
- Broken link detection
- Spam pattern identification
- Export analysis to CSV
