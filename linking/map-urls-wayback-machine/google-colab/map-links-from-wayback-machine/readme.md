# Map Links from Wayback Machine - Google Colab Version

## Features

Google Colab notebook version of the Wayback Machine link mapper. Find and recover broken backlinks using archive.org data.

- Run directly in Google Colab
- No local installation required
- Maps old URLs to new destinations
- Identifies link recovery opportunities
