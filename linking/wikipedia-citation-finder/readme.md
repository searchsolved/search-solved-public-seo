# Wikipedia Citation Finder

## Features

Find Wikipedia pages with "citation needed" tags that you could potentially cite with your content. Great for building high-authority backlinks.

- Streamlit web interface
- Searches Wikipedia for citation opportunities
- Exports results to Word document with clickable links
- English Wikipedia support
