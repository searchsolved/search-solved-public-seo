# Striking Distance Creator - Legacy Colab Notebooks

## Features

Legacy Google Colab versions of the striking distance keyword tool.

- **CSV Version** - Upload keyword exports from Ahrefs/SEMrush
- **GSC Version** - Connect directly to Google Search Console API

> **Note:** These are legacy versions. See the parent folder for the latest Python script version.
