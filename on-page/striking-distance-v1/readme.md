# Striking Distance Keywords

## Features

Identify keywords ranking in "striking distance" (positions 4-20) that could be pushed to page one with on-page optimization.

- Connects to Google Search Console API
- Cross-references with crawl data (Title, H1, Copy)
- Identifies optimization opportunities
- Highlights keywords missing from key page elements

## Versions

- **Python Script** - `striking_distance_report.py` - Local execution with GSC API
- **Legacy Colab Notebooks** - See `legacy-code/` folder for CSV and GSC versions
