# AdWords Tools

## Features

Streamlit app suite for Google Ads tools including MPN Extractor and Bid Calculator.

### MPN Extractor
- Extract MPNs and brands from search term reports
- Identify product-specific search queries
- Clean and categorize search terms

### Bid Calculator
- Calculate optimal bid adjustments
- Device, location, and time-based adjustments
- Performance optimization recommendations
