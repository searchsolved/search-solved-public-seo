# Content Decay Analyzer

## Features

Analyze GSC data to find pages losing traffic, comparing peak month performance vs current month with Excel export.

- Streamlit web interface + CLI version
- GSC data integration
- Peak vs current comparison
- Traffic decay detection
- Prioritize content updates
- Export analysis to Excel
