# Core Update Analyser

## Features

Group Ahrefs keyword ranking changes by URL folder to show which site sections gained/lost rankings across core updates.

- Streamlit web interface
- Ahrefs data integration
- Folder-level analysis
- Core update impact tracking
- Winners and losers identification
- Export analysis to CSV
