# ⚠️ [LEGACY] Create a BCG Matrix from Google Analytics

> **Legacy Tool:** This tool was built for Universal Analytics (UA) exports which Google sunset in July 2023. It expects UA column names (Sessions, Revenue) which differ from GA4 exports. Use with caution or adapt for GA4 data.

## Features

Easily identify high value pages and categories from landing page reports.
