# Google Trends Forecasting - Single Keyword Version

## Features

Forecast Google Trends data for individual keywords using NeuralProphet. Perfect for understanding seasonal patterns and predicting future search interest.

- Streamlit web interface
- Uses NeuralProphet for explainable time-series forecasting
- Visualize historical trends and predictions
- Identify seasonality and growth patterns
