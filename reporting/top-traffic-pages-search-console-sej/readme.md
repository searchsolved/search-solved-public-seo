# Top Traffic Pages - Search Console API

## Features

Google Colab notebook to identify your top traffic pages using the Search Console API. As featured on Search Engine Journal.

- Connect directly to Google Search Console
- Identify highest-performing pages
- Analyze clicks, impressions, CTR, and position
- Export data for further analysis
