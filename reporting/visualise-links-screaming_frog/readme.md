# Visualise Internal Links with Treemaps

## Features

Visualize your internal linking structure using interactive treemaps. Works with data from Screaming Frog, Ahrefs, or Search Console.

- Google Colab notebook
- Supports multiple data sources (Screaming Frog, Ahrefs, GSC)
- Interactive treemap visualization
- Spot linking patterns and opportunities at a glance

## Supported File Formats

- Screaming Frog Crawl Export (CSV)
- Ahrefs Backlinks Report
- Search Console Internal/External Links Report
