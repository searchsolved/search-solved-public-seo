# Visualise Search Console Coverage Reports

## Features

Visualize Search Console coverage reports with interactive treemaps and sunburst charts. Quickly spot indexing issues by folder path.

- Google Colab notebook
- Interactive treemap and sunburst visualizations
- Word cloud of most common URL patterns
- Great for identifying "Crawled, not indexed" patterns

## Output

- Interactive Treemap (.html)
- Interactive Sunburst Chart (.html)
- Word Cloud (.png)
