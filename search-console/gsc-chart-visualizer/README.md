# GSC Chart Visualizer

## Features

Streamlit app for GSC data visualization and charting with authentication and custom dimension analysis.

- Streamlit web interface
- GSC API authentication
- Interactive charts
- Custom dimension analysis
- Date range selection
- Export charts and data
