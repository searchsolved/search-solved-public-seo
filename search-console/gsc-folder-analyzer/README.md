# GSC Folder Analyzer

## Features

Aggregate GSC data by URL folder/path to analyze site section performance with clicks, impressions, and top keywords.

- Streamlit web interface + CLI version
- Folder-level aggregation
- Performance by site section
- Top keywords per folder
- Click and impression metrics
- Export analysis to CSV
