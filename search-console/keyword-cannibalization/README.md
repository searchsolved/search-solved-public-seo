# Keyword Cannibalization

## Features

Find keywords where multiple pages compete for the same query in GSC data for consolidation opportunities.

- Streamlit web interface + CLI version
- GSC data analysis
- Multi-page query detection
- Cannibalization scoring
- Consolidation recommendations
- Export findings to CSV
