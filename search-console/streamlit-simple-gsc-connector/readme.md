# Simple GSC Connector for Streamlit

## Features

A minimal Streamlit app to connect to Google Search Console and export your data. Perfect as a starting point for building GSC-powered tools.

- OAuth authentication with Google
- Support for multiple search types (web, image, video, news, discover)
- Flexible date range selection
- Export to CSV

## Configuration

Set `IS_LOCAL = True` for local development, `False` for Streamlit Cloud deployment.
