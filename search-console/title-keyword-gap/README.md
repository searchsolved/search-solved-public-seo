# Title Keyword Gap

## Features

Compare GSC keywords against page titles to identify keywords driving impressions but missing from titles.

- Streamlit web interface + CLI version
- GSC data integration
- Title vs keyword comparison
- Gap identification
- Optimization opportunities
- Export gaps to CSV
