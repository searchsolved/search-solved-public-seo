# Semantic Clustering - SEJ Python Version

## Features

Python script version of the semantic keyword clustering tool as featured on Search Engine Journal.

- Groups keywords into topical clusters using sentence embeddings
- Uses machine learning for semantic similarity
- Standalone script for local execution
