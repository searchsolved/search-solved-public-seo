# Firecrawl Markdown Scraper

## Features

Scrape URLs and convert to clean markdown using Firecrawl API with zip export of batch results.

- Streamlit web interface
- Firecrawl API integration
- Clean markdown conversion
- Batch URL processing
- Zip export for bulk downloads
- Perfect for AI/LLM training data
