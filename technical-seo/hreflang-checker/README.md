# Hreflang Checker

## Features

Extract and validate hreflang tags from web pages with user agent configuration and request throttling.

- Streamlit web interface + CLI version
- Hreflang tag extraction
- Validation checks
- User agent configuration
- Request throttling
- Export results to CSV
