# Hreflang Generator

## Features

Generate hreflang XML tags from Screaming Frog crawl data for multi-language site implementation.

- Streamlit web interface
- Screaming Frog data import
- Hreflang XML generation
- Multi-language support
- X-default handling
- Export ready-to-use tags
