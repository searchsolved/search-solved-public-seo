# LLM Sitemap Creator

## Features

Generate hierarchical sitemap structures from keyword lists with search volume data using OpenAI GPT.

- Streamlit web interface + CLI version
- OpenAI GPT integration
- Keyword-based structure
- Search volume consideration
- Hierarchical organization
- Export sitemap structure to CSV
