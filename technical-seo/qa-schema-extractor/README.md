# QA Schema Extractor

## Features

Extract FAQ and Q&A structured data (JSON-LD) from websites or crawl exports.

- Streamlit web interface
- JSON-LD extraction
- FAQ schema parsing
- Q&A schema parsing
- Batch URL processing
- Export schema data to CSV
