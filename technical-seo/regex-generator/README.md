# Regex Generator for SEO

## Features

Generate regex patterns from plain English descriptions using Claude or GPT for SEO tasks like redirects and GSC filters.

- Streamlit web interface
- Claude and GPT API support
- Plain English input
- SEO-focused patterns
- Redirect rules generation
- GSC filter patterns
