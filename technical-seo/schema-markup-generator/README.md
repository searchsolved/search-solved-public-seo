# Schema Markup Generator

## Features

Generate valid JSON-LD structured data for FAQPage, Product, Organization, and other common schema types.

- Streamlit web interface
- Multiple schema types
- FAQPage schema
- Product schema
- Organization schema
- JSON-LD output
- Copy-ready code
