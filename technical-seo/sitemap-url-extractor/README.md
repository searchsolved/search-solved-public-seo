# Sitemap URL Extractor

## Features

Extract all URLs from XML sitemap indexes and child sitemaps with support for gzipped files.

- Streamlit web interface + CLI version
- Sitemap index parsing
- Child sitemap extraction
- Gzip support
- URL deduplication
- Export URLs to CSV
