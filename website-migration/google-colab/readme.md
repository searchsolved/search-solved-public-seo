# Website Migration Tool - Google Colab Version

## Features

Google Colab notebook version of the automatic website migration mapping tool. Map URLs from old site to new site using fuzzy matching.

- Run directly in Google Colab
- No local installation required
- Uses PolyFuzz for intelligent URL matching
- Grid search to find optimal matches across multiple columns
