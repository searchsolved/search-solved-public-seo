# Website Migration Tool - Python Script Version

## Features

Standalone Python script for automatic website migration URL mapping. Uses a grid search to find the highest scoring match between source and destination URLs.

- Local execution without dependencies on cloud services
- Uses PolyFuzz for intelligent fuzzy matching
- Configurable matching columns (URL, Title, H1, etc.)
- Handles character encoding detection automatically
